# בדיקות אוטומטיות

הבדיקות האלה בודקות את כל נקודות ה-API של האפליקציה בלי לגעת באינטרנט, במסד אמיתי או בסודות אמיתיים.
כל מה שהקוד צריך (מסד, fetch, שעון) מוחלף במחליפים מזויפים שרצים בזיכרון.

אנלוגיה: זה כמו אימון בלי תחרות. הקוד רץ, מישהו מודד אותו, ואם משהו נשבר רואים מיד לפני שזה מגיע למשתמשים.

## איך מריצים

מהתיקייה הראשית של הפרויקט:

```
node --test "test/*.test.js"
```

אין צורך להתקין שום דבר. זה משתמש בכלי הבדיקות שמובנה ב-Node.

הערה: הפקודה `node --test test/` (עם סלאש) לא עובדת ב-Node 24. משתמשים בפקודה שלמעלה (עם המרכאות).

בדיקה אחת בלבד:

```
node --test test/intake.test.js
```

## איך קוראים את התוצאה

- `pass` - בדיקות שעברו.
- `fail` - בדיקות שנכשלו. אם יש כאלה, משהו נשבר ואסור לפרסם.
- `todo` - בדיקות שמסומנות "באג ידוע". הן נכשלות בכוונה כי הקוד עצמו עדיין לא תוקן. הן לא מפילות את הריצה.

## מה כל קובץ בודק

| קובץ | מה הוא בודק |
|---|---|
| `intake.test.js` | קליטת הודעה מהקיצור: סוד, שיטות, קלט ריק או מוזר, עברית, כשלי מסד |
| `cron-plan.test.js` | ה-Cron: סוד, רישום ב-probe_log, והשעה בישראל סביב מעבר שעון הקיץ (25.10.2026) |
| `vapid-public-key.test.js` | הגשת המפתח הציבורי, ושהמפתח הפרטי אף פעם לא נחשף |
| `push-subscribe.test.js` | רישום מנוי להתראות: אימות, גודל, כתובות לא חוקיות, פרטיות |
| `push-send.test.js` | שליחת התראות: כפילויות (dedupe), שגיאות 410 ו-429, כשלים, פרטיות |
| `lib-push.test.js` | הפונקציות של התראות: בדיקת מנוי, בניית ההודעה, ניקוי שגיאות, השולח |
| `lib-google.test.js` | הצפנה (כולל מפתח שגוי וזיוף), state, OAuth, רשימת יומנים, טוקן הערוץ |
| `google-auth-start.test.js` | תחילת חיבור ל-Google |
| `google-auth-callback.test.js` | החזרה מ-Google: הגנה מפני שימוש חוזר ב-state, הצפנת הטוקן, אבטחת הדף |
| `google-calendars.test.js` | רענון גישה וקריאת רשימת היומנים, כל סוגי הכשלים |
| `google-watch-start.test.js` | פתיחת ערוצי watch: הרשאות, כפילויות, כשלים חלקיים, פרטיות |
| `google-webhook.test.js` | קליטת התראות מ-Google: זיהוי ערוץ, אימות טוקן, מונים |
| `gate-probe.test.js` | בדיקת השער מול Gemini: ציון, סף 90%, עצירה ב-429, פרטיות |
| `default-exports.test.js` | שהעטיפה של כל נקודה נטענת ודוחה בקשות לא מתאימות |

קבצי עזר (לא בדיקות): `helpers.js` (מסד ו-fetch מזויפים) ו-`google-fixtures.js` (נתוני Google מומצאים).

## מה חשוב לדעת

- כל הסודות בבדיקות מומצאים ומוגדרים בתוך הבדיקה. שום סוד אמיתי לא נקרא.
- בדיקות "פרטיות" מוודאות שסוד, טוקן, כתובת התראה או שם יומן לא מופיעים בתשובה ולא בלוג.
- אם מוסיפים נקודת API חדשה: ייצא `handle(request, deps)` כמו בשאר, והוסף קובץ `שם.test.js`.
