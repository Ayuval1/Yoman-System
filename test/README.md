# בדיקות אוטומטיות

הבדיקות האלה בודקות את כל נקודות ה-API של האפליקציה בלי לגעת באינטרנט, במסד אמיתי או בסודות אמיתיים.
כל מה שהקוד צריך (מסד, fetch, שעון) מוחלף במחליפים מזויפים שרצים בזיכרון.

אנלוגיה: זה כמו אימון בלי תחרות. הקוד רץ, מישהו מודד אותו, ואם משהו נשבר רואים מיד לפני שזה מגיע למשתמשים.

## איך מריצים

מהתיקייה הראשית של הפרויקט:

```
node --test "test/*.test.js"
```

אין צורך להתקין שום דבר. זה משתמש בכלי הבדיקות שמובנה ב-Node.

הערה: הפקודה `node --test test/` (עם סלאש) לא עובדת ב-Node 24. משתמשים בפקודה שלמעלה (עם המרכאות).

בדיקה אחת בלבד:

```
node --test test/intake.test.js
```

## איך קוראים את התוצאה

- `pass` - בדיקות שעברו.
- `fail` - בדיקות שנכשלו. אם יש כאלה, משהו נשבר ואסור לפרסם.
- `todo` - בדיקות שמסומנות "באג ידוע". הן נכשלות בכוונה כי הקוד עצמו עדיין לא תוקן. הן לא מפילות את הריצה.

## מה חשוב לדעת

- כל הסודות בבדיקות מומצאים ומוגדרים בתוך הבדיקה. שום סוד אמיתי לא נקרא.
- בדיקות "פרטיות" מוודאות שסוד, טוקן, כתובת התראה או שם יומן לא מופיעים בתשובה ולא בלוג.
- אם מוסיפים נקודת API חדשה: ייצא `handle(request, deps)` כמו בשאר, והוסף קובץ `שם.test.js`.
