## הכרעות שהתקבלו (4.10.2026, יובל)

1. **מוח:** Agent SDK (לא `claude -p`). **בלי פנייה כתובה ל-Anthropic** (החלטת יובל). Gemini (מסלול חינמי, בלי פרטי תשלום) הוא **המועדף אם יעבור את הבדיקות בשער**; Claude נשאר חלופה. הבדיקות: `15-gate-success-criteria.md`. חשיפה ידועה: במסלול החינמי התוכן עשוי לשמש את Google; הקוד יסיר שמות וטלפונים לפני השליחה.
2. **דחיפה:** הצהרתית כנקודת פתיחה. בדיקת "שירות-עובד שרק מדווח הגעה" בשלב 4, רק אם דיווח הגעה נדרש. יובל האציל את ההכרעה הטכנית.
3. **דומיין ושם:** כתובת חינמית `yoman-system.vercel.app`, שם תצוגה "מערכת יומן". דומיין בתשלום נפסל (אין תקציב). הפרויקט `yoman-system` נפתח ב-Vercel (אומת בקריאה ב-4.10.2026).
