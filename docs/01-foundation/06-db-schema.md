## קבוצה 1 — מה נכנס

## קבוצה 3 — מה קרה

### `changes` — היסטוריית שינויים

| שדה | סוג | תיאור |
|---|---|---|
| `id` | uuid | |

עדכון מצב לעולם לא מוחק את הקודם. השורה הנוכחית מתעדכנת, והשינוי נרשם כאן.

### `messages` — התקשורת עם יובל

| שדה | סוג | תיאור |
|---|---|---|
| `id` | uuid | |
| `direction` | text | out / in |
| `body` | text | |
| `kind` | text | update / question / approval_request / reminder |
| `sent_at` | timestamptz | |
| `awaiting_reply` | boolean | האם ממתינים לתשובה |
| `reply_source_id` | uuid → sources | התשובה, כשהגיעה |
| `expires_at` | timestamptz | מתי השאלה מפסיקה להיות רלוונטית |
| `entity_type`, `entity_id` | text, uuid | על מה השאלה |
| `attempt` | int | ניסיון בירור מספר כמה |

**בירור פתוח הוא שורה עם `awaiting_reply = true`.** הוא נסגר בתשובה, או כשהנושא חדל להיות רלוונטי (`expires_at`). אין תגובה — נשאר פתוח, והמשימה מסומנת `unknown`.

> **הערה מהערוץ החדש:** השדה `awaiting_reply` הוא כיום גם **מקור האמת לתצוגה** — המספר על אייקון האפליקציה ורשימת הממתינים נגזרים ממנו. לפי עיקרון "התראה אבודה היא עיכוב, לא החמצה" (`03-app-channel-rules.md`), שורה כזאת נסגרת **רק כשיובל אישר בפועל באפליקציה** — לא כששלחנו התראה. שליחה מוצלחת אינה משנה את `awaiting_reply`.

## כללי עבודה עם הסכמה

- **כל שינוי במצב עובר דרך `changes`.** אין עדכון שקט.
- **כל פעולה נשענת על `source_id`.** אין שינוי בלי מקור.
- **סתירה בין קובץ סטטי למסד — הקובץ מנצח.** טעינה חדשה יוצרת `static_loads` חדש, לא דורסת.
- **מה שלא ידוע נשאר לא ידוע.** אין ערך ברירת מחדל שמסתיר חוסר מידע.
- **מחיקה פיזית אסורה.** ביטול הוא סטטוס. ⚠️ **חריג אחד, 1.10.2026:** קובץ התמונה ב-Blob נמחק אחרי אישור שנתי של יובל — **שורת `media` נשארת** עם `status = deleted`.

## ✅ אחסון מדיה — הוכרע 1.10.2026 (פרק 5, שלב 5)

**ההכרעה:** תמונות נשמרות ב-**Vercel Blob, אחסון פרטי**. הקיצור מקטין וממיר ל-JPEG לפני השליחה. נשמרות שנת לימודים; אחרי 20.6 — שאלה אחת ליובל לפני מחיקה. עם כל תמונה — תאריך, ומקצוע כשידוע. **הכללים המלאים:** `03-intake-rules.md` ("הודעה בלי טקסט") · `03-app-channel-rules.md` ("הקלט").

| שאלה שהייתה פתוחה | מה נקבע |
|---|---|
| 1. מה יושב ב-`media_url` | **הוחלף בטבלת `media`**, עם `blob_path` לכל תמונה |
| 2. `file_id` | **לא נוסף** — כפי שסומן |
| 3. `channel` | `app` · `shortcut` · `calendar` · `system` · `file` |

**נפסלו:** base64 במסד (Neon — 1GB לפרויקט מ-2.10.2026, קודם 0.5GB; מקור: https://neon.com/docs/changelog/2026-10-02; כשמתמלא *"inserts, updates, deletes"* נכשלים — תמונות יכולות לעצור את היומן) · שמירה באפליקציה (הקיצור שולח לשרת, והאפליקציה אינה מאחסנת) · Google Drive (בחירת יובל) · Cloudflare R2 (דורש כרטיס אשראי) · Supabase (מושהה אחרי שבוע בלי שימוש).

**אילוץ מחייב — נשמר:** עלות אפס. Vercel Blob ב-Hobby: *"you will not pay for any additional usage"*; מעבר לתקרה — נחסם ל-30 יום. [מקור](https://vercel.com/docs/vercel-blob/usage-and-pricing)
