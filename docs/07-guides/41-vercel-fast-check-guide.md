## דרך 1: שורה אחת בטרמינל (מהמחשב)

מדביקים ב-PowerShell או ב-Git Bash ומריצים:

```bash
vercel logs --project yoman-system --scope yuval-amars-projects --environment production --no-branch --since 1h
```

**איך קוראים:** כל שורה היא בקשה אחת. תסתכל על שתי עמודות:
- **STATUS `200`** = הבקשה התקבלה. זה מה שרוצים לראות ליד `POST /api/intake`.
- **STATUS `401`** = הסוד שגוי. **`405`** = שיטה שגויה.
- אם אין שורה בכלל: או שלא נשלחה בקשה, או שעברה יותר משעה (בחשבון החינמי הלוגים נשמרים שעה).
- **השעה בשעון ישראל**, לא UTC.

**אומת 10.10.2026:** הראה `21:31:04 POST /api/intake 200` ברגע ששלחת שתי הודעות לקיצור.

## דרך 2: לראות מה נשמר (מהמחשב, וגם מה-iPad)

1. פותחים את הקישור הזה ושומרים אותו בסימניות:
   `https://vercel.com/yuval-amars-projects/yoman-system/integrations/neon/icfg_vFBDxKJVJmI11gZs4OoewHCU/resources/storage/store_vD2YGYvK5bTxtwo2/query`
2. בודקים שהמתג **Read-only** כחול (דלוק). אם כבוי, לא ממשיכים.
3. מוחקים את מה שכתוב בתיבה, מדביקים **פקודה אחת**, ולוחצים Run:

```sql
SELECT channel, received_at, length(raw_content) AS len, (processed_at IS NOT NULL) AS processed FROM sources WHERE received_at > now() - interval '90 minutes' ORDER BY received_at DESC LIMIT 10;
```

**איך קוראים:** שורה לכל הודעה שנקלטה. `received_at` ב-UTC (שלוש שעות אחורה משעון ישראל בקיץ). `processed` יהיה `f` עד שנבנה שלב 8.2, וזה תקין.

**לא נבדק:** פתיחת הקישור ישירות מה-iPad.
