# צוות הבנייה

## מי הצוות
- **מנהל:** קורא את יומן הבעיות, מחליט מה מתקן הלילה ומה מחכה ליובל.
- **בנאי:** מציע ומבצע תיקון בקוד.
- **מעצב:** מציע תיקון במה שנראה ומרגיש על המסך.
- **בודק:** מוצא ומספר בעיות. רק מדווח, לא מתקן.

## איפה הכול
- יומן הבעיות: `docs/10-team/problem-log.md`
- דוחות בוקר ליובל: `docs/10-team/reports/` (קובץ לכל יום, `YYYY-MM-DD.md`)
- הסקילים: `.claude/skills/end-of-day-meeting/`, `.claude/skills/morning-report/`, `.claude/skills/phone-checklist/`

## השיטה
1. הבודק רק מדווח. הוא לא מתקן.
2. ישיבת סוף יום: המנהל קורא את היומן, הבודק מספר, הבנאי והמעצב מציעים, המנהל מחליט.
3. מיזוג ל-`main` רק אם `node --test "test/*.test.js"` נגמר עם `fail 0`.
4. כל מה שנוגע במסד, בהרשאות, בסודות או במחיקת קבצים לא מתוקן בלילה. הוא נרשם בדוח תחת "מחכה ליובל".
5. בבוקר יובל מקבל דוח של שלוש שורות: נמצא, תוקן, מחכה לך.
