## ⏳ מה מחכה ליובל

1. **סנכרון למחשב** (בתיקיית הריפו):
   ```bash
   git checkout main
   ```
   ```bash
   git pull
   ```
2. **להריץ את המבחן על `gemini-3.1-flash-lite`.** במבחן האחרון הוא ענה נכון על 16 מתוך 17, ושלושה משפטים לא הספיקו לרוץ. הפקודה ממשיכה רק את מה שנשאר. אם יצאו 18 נכונות או יותר, הוא עובר. צריך את `CRON_SECRET`. ב-PowerShell:
   ```powershell
   $s = Read-Host "CRON_SECRET" -AsSecureString; $p = [Runtime.InteropServices.Marshal]::PtrToStringAuto([Runtime.InteropServices.Marshal]::SecureStringToBSTR($s)); [Console]::OutputEncoding = [Text.Encoding]::UTF8; Invoke-WebRequest -Method GET -Uri "https://yoman-system.vercel.app/api/ops?task=gate-probe&model=gemini-3.1-flash-lite&resume=1" -Headers @{Authorization="Bearer $p"} -UseBasicParsing -TimeoutSec 310 | Select-Object StatusCode, Content | Format-List
   ```
   - "עבר: ..." = המודל עבר, והוא מחליף את הפיילוט מעצמו.
   - "כבר עבר" = לא הורץ כלום.
   - **אם עברו יותר מ-36 שעות מהריצה של 23.11 13:11,** המבחן רץ מההתחלה על כל 20 המשפטים.
   - **חשוב:** ה-Cron של 06:50 בבוקר (04:50 UTC) כנראה ימשיך את אותו מודל בעצמו, כי מודל עם ריצה שנקטעה מקבל עדיפות. אם כן, הפקודה תחזיר "כבר עבר". (הנחה, לא אומת.)
3. **קישור תמונות ישנות לשיעור** (`CRON_SECRET`). קודם בלי לכתוב כלום, רק לראות כמה ייקשרו:
   ```powershell
   $s = Read-Host "CRON_SECRET" -AsSecureString; $p = [Runtime.InteropServices.Marshal]::PtrToStringAuto([Runtime.InteropServices.Marshal]::SecureStringToBSTR($s)); [Console]::OutputEncoding = [Text.Encoding]::UTF8; Invoke-WebRequest -Method GET -Uri "https://yoman-system.vercel.app/api/ops?task=lesson-backfill" -Headers @{Authorization="Bearer $p"} -UseBasicParsing -TimeoutSec 120 | Select-Object StatusCode, Content | Format-List
   ```
   ואז אותה פקודה, עם `&apply=1` בסוף הכתובת. אם בתשובה יש `next_before` שאינו `null`, מריצים שוב עם `&before=<הערך>`.
4. **ב-Google:** לוודא שיש יומן בשם **"לימוד"**. אם אין, שעות הלמידה יופיעו רק באפליקציה ולא ב-Google. מספיק ליצור יומן בשם הזה, בלי שום שינוי בקוד.
5. **בדיקות באייפון:** `docs/10-team/phone-check-2026-11-24-night.md` (15 שורות).
6. **סוד חדש:** אין. **פקודת מסד:** אין. אף תכונה הלילה לא צריכה עמודה או טבלה חדשה.

**איך לראות שהפיילוט עובד** (במסד, ב-Neon, קריאה בלבד):
```sql
SELECT date_trunc('day', at) AS day, detail, count(*) FROM probe_log WHERE probe = 'brain-pilot' GROUP BY 1, 2 ORDER BY 1 DESC, 3 DESC;
```
- `outcome=ok` = המוח הבין את ההודעה.
- `format` = הבדיקה בקוד דחתה את התשובה, והקוד טיפל בהודעה בעצמו.
- `quota` = נגמרה המכסה.

ההסכמה בין המוח לקוד: שורות `probe = 'brain-intake'`, כש-`ok` אומר אם הם הסכימו.

**מצב כל מודל במבחן** (לא נבדק בסשן הזה: אין לי גישה למסד):
```sql
SELECT DISTINCT ON (m) m AS model, ok, substring(detail from '(\d+/\d+) ran=') AS score, at FROM (SELECT substring(detail from 'model=([^;| ]+)') AS m, ok, detail, at FROM probe_log WHERE probe = 'gate-gemini') t WHERE m IS NOT NULL ORDER BY m, at DESC;
```
